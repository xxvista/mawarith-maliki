# mawarith-maliki — حاسبة المواريث على المذهب المالكي

Arabic (RTL) single-page inheritance calculator and teaching tool following the Maliki school, with the Algerian Family Code options (radd, dhawu al-arham, tanzil) and takharuj.

- `engine.js` — calculation engine (exact BigInt fractions)
- `ui.js` — interface, explanations, lessons and exercises
- `template.html` — page shell and styles
- `build.py` — builds `index.html` (self-contained)
- `test.js` — regression tests: `node test.js`

See `progress.md` and `bugs.md`.
